Model tree view (spec: model-tree-view). Native VS Code TreeView, so styling comes from the theme. Elements view (default): workspace folder → folders → .sysml files → elements. Folders with no SysML file below them are dimmed, marked “no SysML files” and cannot be expanded; excluded folders (files.exclude, sysml.exclude, e.g. node_modules) are not shown. The filter button (⧉) in the title bar switches to the Diagrams view (below), which keeps the folders but shows .sysmld files as leaves with their kind and dims folders with no diagrams. Also shows kind icons, type descriptions, a file with parse errors, the context menu, and selection synced from the text editor. A search box above the tree (a small webview with one input and a clear button; Escape clears) filters the active view to the names that match plus the folders, files and owners leading to them, expanded; nothing matching shows “No matches”. With no folder open a welcome message offers Open Folder. All mockups

    part def Vehicle {
        part engine : Engine;        // cursor here → tree selects "engine"
        part transmission : Transmission;
        part wheels : Wheel[4];
        attribute mass : MassValue;
        connect engine.drive to transmission.input;
    }

    part def Transmission { port input : ~DrivePort; }
    part def Wheel;
    port def DrivePort;
}
